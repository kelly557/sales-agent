Agent 如何获取数据SQL / MCP / API / FILE / VECTOR
SQL 业务库查询

通过只读视图或数据集市读取 CRM、ERP、项目系统。按 tenant_id、组织、项目权限过滤，输出结构化字段与来源表版本。

MCP 工具调用

把标准库、网盘、PDM、BIM、审批系统封装成可审计工具。Agent 传入项目、产品、行业上下文，MCP 返回字段化结果与证据链接。

API 实时接口

面向价格、库存、状态、认证有效期、审批结果等动态信息。每次生成前按 TTL 校验，避免使用过期参数。

文档解析与对象存储

上传文件、历史方案、图纸、照片、报告进入 S3 / 企业网盘，抽取章节、表格、图片、页码、文件哈希，形成 source_refs。

向量 / 关键词检索

对标准条款、案例、FAQ、产品手册做混合召回。返回片段、相似度、公开级别、引用页码，供问答、审核和生成使用。

Hermes 记忆读取

从任务记录、反馈记录、客户画像取偏好、常用模板、历史修改口径。只作为个性化上下文，不覆盖强规则和主数据。

链路
1. 意图与权限识别任务、行业、项目、客户，校验 permission_scope。
→
2. 连接器编排SQL / MCP / API / 文档解析 / 检索并行取数。
→
3. 字段归一映射到统一接口、保留业务口径、来源和置信度。
4. 规则校验单位、枚举、认证范围、标准条款、公式版本校验。
→
5. Agent 执行生成、计算、检索、审核按统一字段消费数据。
→
6. 回写与学习结果、人工修正、反馈写回任务记录与 Hermes。
