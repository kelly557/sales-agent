核心用户旅程地图

AI Presales Solution Assistant · User Journey Map

问答查询 方案生成 客户记忆 交付沉淀

前期准备

行业包、知识库、模板、规则和权限属于企业初始化与持续运营内容。用户登录后直接提问、上传资料、点击任务入口，Agent 在后台识别任务上下文，并调用 Hermes 客户记忆。

Hermes：记住客户偏好、项目背景、常用模板和历史修改，让下一次交付更贴近客户。
首页入口
帮我查这个项目适用哪些标准。
问答查询 方案生成 技术说明 用量计算 文档审核
后台准备 企业资料入库、行业场景包、模板、公式、审核规则、合规词库、权限和输出格式由实施与运营服务预先配置；Hermes 持续沉淀客户偏好。

核心旅程：用户操作、Agent 执行与 Hermes 学习点

USER JOURNEY
1

发起需求

用户操作

在 AI 输入框直接问，或点击方案生成、计算、审核等入口；可以拖拽上传客户资料。

Agent 执行
  • 识别身份、角色、项目权限和可访问资料范围
  • 判断任务意图：搜索 / 生成 / 计算 / 审核
  • 解析客户、行业、交付物类型和紧急程度
  • 拆解执行步骤，预估所需资料、工具和确认点
  • 形成任务摘要并追问缺失信息
产品交互

首页不暴露复杂配置；用自然语言、快捷入口、历史任务继续和最近资料引用降低启动成本。

输出结果

生成任务卡片，包含任务类型、交付物类型、预计章节、资料范围、缺失信息和执行进度入口。

确认动作

用户确认交付目标、客户对象、输出格式、资料使用范围和关键约束。

Hermes 学习

记录用户常问问题、客户类型、项目阶段和默认交付目标，下次自动带入。

2

搜索依据

用户操作

查询标准、产品参数、项目资料、历史案例，继续追问或筛选结果。

Agent 执行
  • 识别问题里的工程对象、产品型号和适用场景
  • 同时执行语义检索、关键词检索和权限过滤
  • 按标准、产品、项目、案例多源召回资料
  • 抽取条款、参数、页码、版本和相似案例
  • 合并重复来源，生成带出处的适用性答案
产品交互

结果按标准、产品、项目、案例分类；展示文件、页码、条款和原文定位。

输出结果

输出依据清单、条款摘要、原文定位、适用说明、相似案例和可加入方案的引用片段。

确认动作

用户确认资料版本、适用边界、引用是否纳入交付物，以及是否继续追问或生成。

Hermes 学习

沉淀客户关注的标准、产品型号和案例类型，后续推荐更贴近真实需求。

3

补齐上下文

用户操作

上传客户需求、项目文件或产品资料，补充现场条件、交付对象和格式。

Agent 执行
  • 解析上传文件、表格、图片和客户需求说明
  • 抽取工程对象、现场条件、限制条件和关键参数
  • 识别缺失字段、冲突信息和需要人工确认的假设
  • 关联已检索依据、客户历史和项目资料
  • 生成可编辑项目上下文和资料范围清单
产品交互

显示文件解析状态、缺失字段追问、任务摘要预览和可编辑上下文。

输出结果

输出结构化需求表、项目条件、客户关注点、资料清单、待补字段和可编辑任务摘要。

确认动作

用户确认假设条件、关键参数、资料范围、客户口径和是否允许使用历史案例。

Hermes 学习

把客户需求、现场条件、交付对象和口径偏好转为可复用项目记忆。

4

生成 / 计算

用户操作

选择生成 PPT、Word、报告或发起用量计算，确认大纲和关键参数。

Agent 执行
  • 按客户类型、场景和交付物匹配模板与章节结构
  • 规划 PPT / Word 页面，分配标题、正文、表格和案例位
  • 调用公式、材料表、单位换算和计算规则
  • 将依据、产品参数、案例和计算结果写入对应章节
  • 执行引用完整性、参数一致性和格式自检
产品交互

大纲预览、参数表单、计算过程展开、生成进度、分章节刷新。

输出结果

生成解决方案 PPT 初稿：项目背景、需求分析、产品推荐、技术方案、案例、实施计划、报价/用量附表；章节和文案可编辑。

确认动作

用户确认大纲结构、推荐产品、关键参数、公式口径、案例使用和最终导出格式。

Hermes 学习

学习用户采纳的大纲、模板、措辞和参数口径，让后续初稿更接近可交付版本。

5

审核

用户操作

选中段落要求改写、补依据、压缩或外发前发起审核。

Agent 执行
  • 定位用户选中段落、所属章节和原始依据
  • 保持技术含义，生成多种改写或压缩版本
  • 检查新增表述是否有来源、参数或认证支撑
  • 识别技术冲突、合规风险、引用缺口和广宣风险
  • 按风险等级输出建议、替代措辞和处理优先级
产品交互

侧边 AI 助手、局部重写、版本对比、风险高亮、一键采纳建议。

输出结果

输出可采纳修订稿、风险清单、依据缺口、审核报告和修改前后对比，支持逐条处理。

确认动作

专家确认高风险结论、认证边界、外发措辞、引用依据和是否允许一键替换。

Hermes 学习

记录用户最终采纳的修改风格、风险处理方式和外发措辞偏好。

6

交付沉淀

用户操作

处理未确认项，锁定最终版，导出 Office / PDF / Excel 或回写系统。

Agent 执行
  • 汇总未确认参数、风险项和待复核结论
  • 执行导出前检查：来源、格式、附件和权限
  • 保存版本、依据链、计算过程和审核记录
  • 生成归档标签、复用摘要和客户反馈字段
  • 推荐沉淀为模板、案例、FAQ 或知识片段
产品交互

导出前检查、角色化确认、最终版锁定、归档提醒、复用标签。

输出结果

输出正式 PPT / Word / PDF / Excel、证据包、版本记录、确认记录和可复用案例标签。

确认动作

用户锁定最终版；管理员确认是否入库为模板、案例、FAQ 或客户偏好资产。

Hermes 学习

沉淀最终交付件、客户反馈和复用标签，形成下一次任务的推荐依据。

产品功能亮点

HIGHLIGHTS
登录即用用户不选择行业包、不配置规则，直接从问答或任务入口开始。
问答与任务打通搜索到的依据可以进入生成、计算和审核，不停留在一次性回答。
越用越懂客户沉淀客户偏好、项目背景、模板选择和历史修改记录。
全流程可追溯段落、参数、结论和风险建议都能回到来源、规则和人工确认。
