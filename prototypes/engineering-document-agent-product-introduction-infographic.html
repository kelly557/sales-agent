01 产品定位

DEFINITION

AI销售助手

产品定位：
面向建筑、装备、能源、电力、化工、涂料等工程领域行业，赋能销售在售前/售中阶段复杂任务, 把标准、产品资料、项目经验和行业知识转化为可查询、可生成、可计算、可审核的知识，快速产出可信、可追溯的交付成果。

用户痛点：资料难找 / 依据难追 / 计算易错 / 审核低效。

价值结果：缩短产出周期 / 降低整理成本 / 提高质量与技术结论可信度 / 经验可沉淀。

03 Hermes 设计

USER MEMORY

关注用户和客户的长期上下文：每次提问、修改、确认和交付，都会沉淀为可复用的客户理解。

客户价值

下次生成更贴近客户需求、项目背景、行业习惯和企业表达风格，减少反复沟通和重复改稿。

记住客户偏好理解项目上下文复用历史交付 学习修改习惯推荐常用模板沉淀最佳表达
价值边界Hermes 不替代查询、计算和审核能力，而是在这些任务之上持续学习客户、项目和交付偏好。

07 关键判断

TAKEAWAYS
Hermes 不是单点功能

它让每次使用都沉淀客户理解，让查询、生成、计算和审核的结果越来越贴近真实业务场景。

核心壁垒来自持续学习

更重要的是客户偏好、项目经验、常用模板、修改习惯和企业表达方式的持续沉淀。

适用边界

AI 辅助查询、计算、生成和审核；关键参数、技术结论、合规风险仍需人工确认。
