01 产品定义

DEFINITION

面向工程行业的文档任务 Agent

把分散工程资料转化为可查找、可生成、可计算、可审核、可交付、可追溯的企业 AI 能力。

04 行业场景包优先级

SCENARIOS
第一梯队涂料 / 装备 / 电力设备 / 化工设备生成价值强，资料相对结构化，销售和交付都有明确需求。
第二梯队能源 / 电力 / 轨交 / 化工交付资料和合规审核价值高，行业门槛更高。
第三梯队建筑 / 基建 / 水利 / 矿山资料量大但现场数据更脏，流程依赖更重。
行业包术语 / 对象 / 模板 / 规则加载文档类型、默认模板、默认规则和 Agent 工作流。
关键对象设备 / 材料 / 图纸 / 报告BOM、P&ID、TDS/SDS、试验报告、检验批、验收资料。

05 产品全景架构

ARCHITECTURE
用户层工程技术人员 / 交付资料人员 / 技术销售与方案人员 / 知识标准负责人 / 管理员与实施人员
入口层独立终端：网页版、小程序；协同端：企业微信、CRM
业务价值层快速查找依据 / 高质量生成文档 / 工程参数与完整率计算 / 技术符合性与缺口审核
能力层查找规范、资料和案例；生成 PPT、指导书、技术说明；计算参数和完整率；审核符合性和缺口
任务执行层项目上下文 / 资料引用 / 过程透明 / 中间结果 / 风险提示 / 人工确认 / 导出回写
知识资产中心标准规范 / 案例经验 / 模版资产 / 规则资产 / 项目成果
工具集成层企业内部 API 连接器 / MCP 工具注册中心 / 多源异构数据抓取引擎
交付成果层方案与指导书 / PPT 与推广材料 / 审核矩阵 / 缺口清单 / 设备档案 / 引用证据包
治理保障层系统权限 / 引用溯源 / 规则校验 / 人工复核 / 审计日志

06 四类能力地图

CAPABILITY
查找标准规范、设备资料、历史案例、项目资料定位。资料列表 / 引用依据
生成方案、作业指导书、技术说明、推广材料、交付报告。Word / PPT / PDF
计算材料用量、工程参数、资料完整率、版本差异。过程 / 来源 / 异常
审核技术符合性、资料缺口、设备完整性、变更影响。矩阵 / 风险 / 补件

07 任务执行页作业台

WORKBENCH
左侧：任务上下文当前项目、行业场景包、工程对象、上传资料、引用源、模板、输出格式。
中间：Agent 执行区解析资料、识别对象、提取参数、生成大纲、生成正文、生成矩阵。
右侧：结果与风险输出文档、引用来源、风险提示、缺失信息、确认项、导出回写。
资料引用项目资料、知识库、API 查询结果、本地上传文件。
人工介入对缺失信息、风险项、关键参数和假设条件进行确认。
交付回写导出 Office/PDF，或推送到企微、邮件、网盘、API。

08 可信交付闭环

TRUSTED LOOP
工程知识
驱动交付资料从存储变成持续产出能力
资料接入分散资料统一可用，多源接入。
知识资产化历史经验可复用，行业场景包。
Agent 执行文档任务自动完成，任务型 Agent。
人工确认关键风险可控，人机协同。
成果交付交付物快速产出，可追溯生成。
反哺沉淀案例、模板、规则越用越强。

09 工程知识底座

KNOWLEDGE
工程对象项目、专业、系统、设备、材料、产品。
标准工艺标准、工艺、图纸、检测报告。
项目记录施工记录、验收资料、历史案例。
模板规则结构模板、内容模板、审核与计算规则。
沉淀机制项目确认结果经人工审核后入库。

10 轻量集成中心

INTEGRATION
P0：消息协同企业微信、飞书、钉钉：发起任务、补件提醒、发送交付链接。
P0：API 查询产品参数、标准条款、项目资料、设备台账、BOM、案例。
P0：文件源上传文件、企业网盘、对象存储、知识库目录。

11 交付成果

DELIVERY
DOC
方案/指导书工程方案、作业指导书、交付报告。
PPT
PPT/推广材料解决方案、技术交流、推广材料。
XLS
矩阵/清单审核矩阵、缺口清单、设备参数表。
