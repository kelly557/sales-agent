01 产品定位

POSITION

把工程资料转化为可交付成果

不是传统文档管理系统，而是围绕工程任务自动完成文档生产、审查、复用、交付和证据留痕。核心输入来自项目资料、产品资料、标准规范与历史案例。

02 用户角色与价值

USERS

一线工程技术人员

快速生成方案、指导书、技术说明；自动引用标准依据；发现遗漏和高风险内容。

项目交付与资料人员

自动识别资料类型、命名归类、检查缺件、生成交付包目录并跟踪补件。

技术销售与解决方案人员

根据客户场景组合产品参数、案例、认证，输出方案、PPT、技术答复和推广材料。

知识与标准负责人

沉淀历史项目、模板、术语和审查规则，控制 Agent 生成边界和引用来源。

05 Agent Native 核心系统

CORE SYSTEM

文档解析中心

Word / Excel / PDF / PPT / OCR / 图片 / CAD 与 P&ID 初步索引。

行业场景包

行业术语、对象模型、模板、资料目录、标准映射和 Agent 工作流。

工程知识底座

项目、专业、设备、材料、标准规范、检测报告、认证和历史案例。

模板与规则库

企业模板、审查规则、参数校验、术语库和禁止生成规则。

Agent 任务引擎 识别场景、规划步骤、检索证据、生成输出并标记人工确认项。
任务入口生成 / 审查 / 整理 / 分析决定 Agent 规划方式与风险阈值。

交付出口Word / PPT / PDF / Excel / 目录包统一生成可审阅、可追溯交付物。

06 通用 Agent 工作流

WORKFLOW
01

任务输入

用户输入项目类型、工程对象、使用环境、技术要求、资料包和输出格式。

02

场景识别

判断行业、专业、任务类型和适用场景包，锁定模板与规则边界。

03

资料解析

抽取元数据、技术参数、表格、签章、版本、编号和原文位置。

04

对象建模

识别项目、系统、设备、材料、工序、验收对象和关联文档。

05

知识检索

匹配企业模板、标准规范、历史案例、产品参数和审查规则。

06

计划执行

生成大纲、审查矩阵、缺口清单、设备档案或变更影响清单。

07

风险标记

对缺失条件、冲突参数、高风险条款设置人工确认和引用证据。

08

输出沉淀

导出可编辑交付物，并沉淀为模板、规则、案例和知识资产。

10 MVP 路线

ROADMAP

MVP 1：方案与指导书

  • 输入需求、资料、模板
  • 生成方案大纲与正文
  • 派生作业指导书
  • 输出引用证据包

MVP 2：缺口与交付包

  • 上传项目资料目录
  • 识别文件类型和元数据
  • 检查缺失、异常、版本冲突
  • 生成交付包目录

MVP 3：审查与建档

  • 技术符合性矩阵
  • 设备资料自动建档
  • 变更影响分析
  • 沉淀规则和案例

11 输出交付物

DELIVERABLES
DOC
工程方案 / 指导书技术路线、施工步骤、质量控制、安全环保、引用依据。
PPT
解决方案材料客户场景、产品体系、参数优势、案例和推广结构。
XLS
审查矩阵符合、不符合、需人工确认、风险等级和原文位置。
ZIP
交付包目录缺失资料、异常资料、补件任务、完整率报告和目录结构。
