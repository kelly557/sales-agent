二、逐产品深度分析

DEEP DIVE / DELIVERY LOOP / PRICING / LIMITS / THREAT
01

金口良策AI

电力工程智能设计平台。最危险的能力不是“会答”，而是把电力类工程交付物直接做出来。

威胁：高

闭环能力

路径规范查询 → 工程计算 → 项目建议书/可研报告 → CAD 图纸 → 工程审核。
场景光伏、风电、储能、输变电、配电，官方已把负荷计算、配电设计、深化出图串成方案。
风险若复制到建筑电气、综合能源、工业电气，将形成垂直降维压力。

价格与销售

公开 SKU 不清晰，官网更多是免费试用、商务咨询、企业智能体定制、私有化部署和生态合作。可信推断为 B2B 项目制/定制化路线。

优势与局限

  • 优势：垂直深、交付物完整，电力工程“文档-计算-出图”雏形已形成。
  • 局限：行业集中在电力/新能源，个人记忆机制不明显。
02

品茗晓筑

建筑施工技术线“总工智能体”。最贴近工程材料交付闭环，也是建筑施工市场必须正面应对的竞品。

威胁：极高

闭环能力

路径查规范/图集/造价/图纸 → 方案编制 → 方案审核 → 图纸关联 → 智能巡检。
资产1 万多本现行规范、图纸版本比对、智能分图、图纸问答、方案知识库。
入口占住施工技术人群日常工作台，比单点材料生成更难替代。

价格与销售

标准版价格公开：专业版 699 元/账号/年，推广期 499 元/年。企业定制和私有化按场景报价，公开线索约 50-100 万元/单。

优势与局限

  • 优势：建筑施工深度强，方案编审闭环明确，客户进入门槛低。
  • 局限：行业边界集中在建筑施工，跨化工、电力制造需要重建专业规则。
03

CAD-KB 工程智能体

CAD + Knowledge Base + Agent。更偏工程企业知识中台，核心变量是图纸语义理解，而不是普通 Office 文档问答。

威胁：中高

闭环能力

路径CAD/DWG/PDF 图纸与 BIM 资料解析 → 工程知识库检索 → 图纸问答 → 图纸 + 规范联合判断 → 图纸校核/合规检查。
场景定位泵房、设备、管线、图元、图层、块参照和标注；关联规范、设计说明和历史项目，回答设计依据与合规问题。
集成预计对接 AutoCAD、天正 CAD、Revit、BIM 平台、OA、PLM、ERP、PM；私有化、API 和 Agent 插件支持度更高。

价格与销售

未发现公开定价，推断偏企业知识库平台和工程知识中台销售：标准版 3-10 万/年，企业版 10-30 万/年，私有化 30-100 万+；工程知识中台 50-300 万/项目，设计院专属 Agent 可能达到 100-500 万+。隐藏成本包括 CAD 解析引擎、图纸向量化、GPU 服务器和年度维保。

优势与局限

  • 优势：图纸级知识库、CAD 解析、图纸 + 规范联合推理和企业工程经验沉淀能力强，明显强于通用 RAG。
  • 局限：完整交付闭环、专业计算、工程文档自动生成、项目管理和归档闭环可能弱于品茗晓筑、良策金宝和文信软件。
04

文信软件

ECM 老牌能力叠加 AI。最大威胁是从大型企业既有文控、归档、权限和流程系统里顺势升级。

威胁：中高

闭环能力

底座企业内容管理、工程信息管理、工程文件一体化、配置、合同、项目管理。
AIAI 知识服务、AI 问数、AI 审核、AI 生成，含设备文档/图纸位号提取与 AI 造价匡算案例。
入口大型工程企业原本就需要文控系统，AI 升级采购阻力较低。

价格与销售

公开 SKU 不明显。AI 智慧平台建设报价线索 665,000 元，更像平台授权、项目实施、定制开发和后续维保组合。

优势与局限

  • 优势：权限、流程、归档、合规和既有系统兼容性更容易落地。
  • 局限：专业内容生成闭环不如品茗/金口良策，更强在文档治理。
05

开目软件

设计-工艺-制造一体化工业软件厂商。对带制造属性的工程客户，是横向切入的高威胁者。

威胁：中高

闭环能力

路径设计模型 → 可制造性审查 → 成本估算 → 三维工艺规划 → 工艺文件/过程卡输出。
资产MBD 模型、工艺知识库、规则推理、制造特征识别、CAD/PLM/MES 集成。
AIAI Agent“小沐”强调用户深度参与、自主更新进化，接近生长型 AI 伙伴叙事。

价格与销售

正式商业版多为咨询报价。3DDFM 官方测试版有 10,000 元/年的公开锚点，同时保留软件交付 + 人工交付的企业项目逻辑。

优势与局限

  • 优势：制造工程规则库、工艺库、成本模型和系统集成扎实。
  • 局限：通用查询、知识生成和归档闭环弱于平台型竞品。

成熟市场与蓝海市场

高成熟建筑施工、工程设计、法律、金融已经出现高成熟垂直 AI 文档产品，行业模板、专业知识和工作流沉淀更充分。
中成熟电力能源和医疗已经有较强垂直产品，但专业细分、数据权限、合规流程仍会影响平台化速度。
蓝海化工、涂料、汽车零部件、通用制造仍处于低成熟阶段，多数企业还在使用“通用大模型 + 知识库”。
机会真正做到行业深度模板化、专业知识沉淀、图纸/工艺/规范联合理解的厂商仍然不多。

商业机会判断

涂料产品资料、配方规则、检测报告、施工说明和客户项目经验可模板化沉淀。
化工规范、工艺包、HAZOP、设备位号、SDS、验收资料具备强知识治理需求。
汽车零部件APQP、PPAP、8D、工艺文件、质量文档和客户标准高度文档密集。
通用制造工艺、质量、设备、供应链和客户交付资料分散，适合从知识中台切入。
