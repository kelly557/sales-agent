总体业务流程

从 Agent 首页进入任务，选择项目和行业场景，完成资料引用、Agent 执行、人工确认、交付和沉淀。

端到端主流程 
flowchart TD
    A["用户进入 Agent 首页"] --> B{"是否已有可用项目"}
    B -->|"是"| C["从我的项目选择项目"]
    B -->|"否"| D["创建轻量项目"]
    D --> C

    C --> E["形成项目上下文"]
    E --> F["选择行业场景包"]
    F --> G["选择任务能力"]

    G --> G1["查找"]
    G --> G2["生成"]
    G --> G3["计算"]
    G --> G4["审核"]

    G1 --> H["选择或输入任务"]
    G2 --> H
    G3 --> H
    G4 --> H

    H --> I["选择资料来源"]
    I --> I1["项目资料"]
    I --> I2["集成资料源"]
    I --> I3["本地上传"]
    I --> I4["知识库/标准库"]

    I1 --> J["文档解析与工程对象识别"]
    I2 --> J
    I3 --> J
    I4 --> J

    J --> K["Agent 执行任务"]
    K --> L{"是否缺少关键信息"}
    L -->|"是"| M["追问用户/请求补充资料"]
    M --> I
    L -->|"否"| N["生成中间结果"]

    N --> O["风险、缺失、引用来源标记"]
    O --> P["人工审阅与确认"]
    P --> Q{"是否通过确认"}
    Q -->|"否"| R["修改条件/调整资料/重新执行"]
    R --> K
    Q -->|"是"| S["生成正式交付物"]

    S --> T{"交付方式"}
    T -->|"导出"| U["导出 Word/PPT/PDF/Excel"]
    T -->|"回写"| V["回写到集成系统"]
    T -->|"归档"| W["沉淀到项目"]

    U --> X["任务完成"]
    V --> X
    W --> X

    X --> Y["沉淀为项目资产/案例/模板/规则"]
