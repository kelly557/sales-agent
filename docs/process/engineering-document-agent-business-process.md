# 工程文档 Agent 业务流程图

本文档基于 `engineering-document-agent-product-plan.md` 梳理业务流程，重点描述产品从我的项目、项目上下文、资料集成、任务执行、人工审阅到交付沉淀的端到端流程。

## 1. 总体业务流程

```mermaid
flowchart TD
    A["用户进入 Agent 首页"] --> B{"是否已有可用项目"}
    B -->|"是"| C["从我的项目选择项目"]
    B -->|"否"| D["创建轻量项目"]
    D --> C

    C --> E["形成项目上下文"]
    E --> F["选择行业场景包"]
    F --> G["选择任务能力"]

    G --> G1["查找"]
    G --> G2["生成"]
    G --> G3["计算"]
    G --> G4["审核"]

    G1 --> H["选择或输入任务"]
    G2 --> H
    G3 --> H
    G4 --> H

    H --> I["选择资料来源"]
    I --> I1["项目资料"]
    I --> I2["集成资料源"]
    I --> I3["本地上传"]
    I --> I4["知识库/标准库"]

    I1 --> J["文档解析与工程对象识别"]
    I2 --> J
    I3 --> J
    I4 --> J

    J --> K["Agent 执行任务"]
    K --> L{"是否缺少关键信息"}
    L -->|"是"| M["追问用户/请求补充资料"]
    M --> I
    L -->|"否"| N["生成中间结果"]

    N --> O["风险、缺失、引用来源标记"]
    O --> P["人工审阅与确认"]
    P --> Q{"是否通过确认"}
    Q -->|"否"| R["修改条件/调整资料/重新执行"]
    R --> K
    Q -->|"是"| S["生成正式交付物"]

    S --> T{"交付方式"}
    T -->|"导出"| U["导出 Word/PPT/PDF/Excel"]
    T -->|"回写"| V["回写到集成系统"]
    T -->|"归档"| W["沉淀到项目"]

    U --> X["任务完成"]
    V --> X
    W --> X

    X --> Y["沉淀为项目资产/案例/模板/规则"]
```

## 8. 人工审阅与追溯流程

```mermaid
flowchart TD
    A["Agent 生成中间结果"] --> B["系统标记风险和引用"]
    B --> C["进入人工审阅"]

    C --> D{"审阅对象"}
    D --> D1["事实内容"]
    D --> D2["表达内容"]
    D --> D3["计算结果"]
    D --> D4["审核判断"]
    D --> D5["缺失信息"]

    D1 --> E["查看来源依据"]
    D2 --> F["直接修改表达"]
    D3 --> G["检查参数和公式"]
    D4 --> H["确认符合/不符合/需补充"]
    D5 --> I["补充资料或确认缺失"]

    E --> J["确认或驳回"]
    F --> J
    G --> J
    H --> J
    I --> J

    J --> K{"是否通过"}
    K -->|"否"| L["返回 Agent 重新执行"]
    L --> A
    K -->|"是"| M["生成正式交付物"]

    M --> N["保存审阅记录"]
    N --> O["形成可追溯证据链"]
```
