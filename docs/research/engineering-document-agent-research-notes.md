# 工程行业文档 Agent 行业调研与场景分析

本文档用于保存产品方案之外的调研材料，包括行业痛点、适合场景、典型输入输出和案例。主产品方案聚焦产品设计，本文件作为其外部依据。

## 1. 行业痛点与适合场景

| 行业 | 文档核心矛盾 | 高价值 Agent 场景 |
| --- | --- | --- |
| 建筑 | 资料量大、过程资料后补、竣工归档压力大 | 施工方案、作业指导书、验收资料缺口检查 |
| 基建 | 标段多、检测资料多、计量/验收链条长 | 专项方案、试验检测资料整理、交付包检查 |
| 装备制造 | 产品资料复杂、技术方案定制化、交付资料繁重 | 技术方案、说明书、检验规程、设备交付包 |
| 能源 | 设备多、调试运维资料重、合规要求高 | 设备资料建档、调试方案、运维移交包 |
| 轨道交通 | 多专业接口复杂、系统集成资料多、认证验收严 | 接口文件审查、技术规格符合性、调试验收资料 |
| 化工 | 工艺安全风险高、P&ID/设备/管道资料强关联 | 变更影响分析、试压方案、设备资料审查 |
| 电力 | 试验报告多、二次/继保资料复杂、移交标准严 | 作业指导书、试验报告整理、竣工移交检查 |
| 矿山 | 安全规程重、设备运维复杂、整改闭环要求强 | 作业规程、安全整改证据链、设备运维资料 |
| 水利 | 验收层级多、监测资料多、工程周期长 | 验收资料检查、监测报告整理、施工方案 |
| 涂料 | 应用方案高度场景化、产品资料需转译成工程方案 | 解决方案、施工指导书、推广资料 |

## 2. 分行业分析

### 2.1 建筑行业

核心痛点：

- 施工资料、验收资料、检验批资料数量巨大。
- 现场过程记录常常后补，真实性和完整性难保证。
- 施工方案、专项方案、技术交底大量重复编写。
- 竣工资料整理高度依赖资料员经验。
- 图纸变更、签证、验收记录之间关联弱。

适合场景：

- 施工方案/专项方案生成 Agent。
- 技术交底生成 Agent。
- 检验批、隐蔽验收、竣工资料缺口检查 Agent。
- 图纸会审与设计变更摘要 Agent。

价值：

- 降低资料员和技术员重复劳动。
- 提高竣工资料完整率。
- 减少方案模板套用错误。

### 2.2 基建行业

包括道路、桥梁、隧道、市政、港口等。

核心痛点：

- 标段多、参建单位多，资料口径不一致。
- 试验检测资料、材料证明、隐蔽验收资料多。
- 施工方案与现场工序、试验资料、计量支付资料存在断点。
- 竣工交付资料按分部分项、单位工程组织，整理复杂。
- 长周期项目中版本和变更追踪困难。

适合场景：

- 试验检测资料整理 Agent。
- 专项施工方案生成 Agent。
- 分部分项验收资料缺口检查 Agent。
- 交工/竣工资料包 Agent。

价值：

- 减少交付前集中补资料。
- 提高检测报告、材料证明和验收资料的对应关系。
- 帮助项目部快速形成标准化交付包。

### 2.3 装备制造行业

核心痛点：

- 技术方案高度定制，售前、设计、制造、交付资料割裂。
- BOM、图纸、检验规程、说明书、合格证、维护手册之间信息重复。
- 设备交付资料包整理成本高。
- 产品说明书和作业指导书更新滞后。
- 新人难以复用历史项目方案。

适合场景：

- 设备技术方案生成 Agent。
- 产品说明书/维护手册生成 Agent。
- 检验规程与出厂资料生成 Agent。
- 设备交付包检查 Agent。
- 历史相似方案复用 Agent。

价值：

- 缩短方案和交付资料制作周期。
- 提高设备资料一致性。
- 把历史项目经验转化为可复用资产。

### 2.4 能源行业

包括新能源、油气、储能、综合能源等。

核心痛点：

- 设备种类多，供应商资料格式不统一。
- 调试、试运行、运维移交资料重。
- 合规、安全、环保资料要求高。
- 多专业、多系统资料之间依赖强。
- 运维阶段找不到建设期资料。

适合场景：

- 设备资料建档 Agent。
- 调试方案/试运行报告生成 Agent。
- 运维移交包 Agent。
- 合规资料缺口检查 Agent。
- 设备故障知识复用 Agent。

价值：

- 打通建设期资料到运维资料。
- 降低设备资料整理成本。
- 提高调试与移交质量。

### 2.5 轨道交通行业

核心痛点：

- 专业多：车辆、信号、通信、供电、站台门、AFC、综合监控等。
- 接口文件复杂，跨专业协调成本高。
- 系统集成测试和联调联试资料量大。
- 安全认证、验收要求严格。
- 变更影响可能跨系统扩散。

适合场景：

- 接口文件审查 Agent。
- 技术规格符合性审查 Agent。
- 联调联试资料整理 Agent。
- 变更影响分析 Agent。
- 验收资料缺口检查 Agent。

价值：

- 降低接口遗漏和规格不一致风险。
- 提升系统集成资料质量。
- 辅助联调联试和验收准备。

### 2.6 化工行业

核心痛点：

- 工艺安全要求高，任何文档错误都可能带来安全风险。
- PFD、P&ID、设备数据表、管道表、仪表表、HAZOP 资料强关联。
- 变更管理复杂，MOC 影响范围难判断。
- 设备、管道、仪表、阀门资料多且版本多。
- 试压、吹扫、单机试车、联动试车资料要求严格。

适合场景：

- P&ID/技术文件变更影响分析 Agent。
- 设备数据表审查 Agent。
- 管道试压方案生成 Agent。
- HAZOP 整改项资料闭环 Agent。
- 调试/试车资料包 Agent。

价值：

- 降低变更遗漏风险。
- 提高设备、管道、仪表资料一致性。
- 辅助安全合规和试车验收。

### 2.7 电力行业

核心痛点：

- 设备试验报告、继保定值、调试记录、竣工资料非常多。
- 一次、二次、通信、自动化资料专业性强。
- 作业指导书和安全措施要求严格。
- 移交运维资料标准化程度高。
- 老旧资料查找和复用困难。

适合场景：

- 作业指导书生成 Agent。
- 试验报告整理 Agent。
- 继保/二次资料审查 Agent。
- 竣工移交资料缺口检查 Agent。
- 运维资料问答 Agent。

价值：

- 减少调试和移交资料整理成本。
- 提高作业文件规范性。
- 帮助运维快速理解设备历史资料。

### 2.8 矿山行业

核心痛点：

- 安全规程、作业规程、整改资料要求重。
- 采掘、通风、排水、提升、运输、选矿等系统资料复杂。
- 设备运行环境恶劣，运维记录和故障资料价值高。
- 安监检查、隐患整改闭环压力大。
- 现场资料不规范，扫描件和图片多。

适合场景：

- 作业规程生成 Agent。
- 安全整改证据链 Agent。
- 设备运维资料整理 Agent。
- 隐患排查报告生成 Agent。
- 合规检查资料缺口 Agent。

价值：

- 提高安全资料规范性。
- 降低隐患整改闭环遗漏。
- 沉淀设备故障和维护经验。

### 2.9 水利行业

核心痛点：

- 项目周期长，阶段验收、专项验收、竣工验收资料复杂。
- 施工、监理、检测、监测资料数量大。
- 大坝、水闸、泵站、堤防、渠道等工程对象差异明显。
- 运行期监测资料与建设期资料割裂。
- 防洪调度、运行维护文档专业性强。

适合场景：

- 验收资料缺口检查 Agent。
- 施工方案生成 Agent。
- 监测报告整理 Agent。
- 运行维护手册生成 Agent。
- 专项验收资料包 Agent。

价值：

- 降低验收资料整理难度。
- 提高监测资料利用率。
- 支撑建设到运行移交。

### 2.10 涂料行业

核心痛点：

- 产品资料多，但客户真正需要的是应用解决方案。
- TDS、SDS、检测报告、认证、案例之间需要人工组合。
- 不同底材、环境、施工条件对应不同体系。
- 技术销售和应用工程师编写方案、PPT、施工指导书耗时。
- 产品参数不能乱写，必须可追溯。

适合场景：

- 涂装解决方案生成 Agent。
- 施工作业指导书生成 Agent。
- 产品推广 PPT/PDF 生成 Agent。
- 技术要求符合性审查 Agent。
- 竞品替代方案 Agent。

价值：

- 把产品知识转化为销售和工程交付材料。
- 提高方案响应速度。
- 降低新人对专家经验的依赖。

## 3. 核心场景输入输出

### 3.1 工程方案生成 Agent

适用行业：

- 建筑
- 基建
- 水利
- 能源
- 化工
- 电力
- 矿山
- 轨道交通
- 涂料
- 装备制造

用户输入：

- 项目类型
- 工程对象
- 使用环境
- 技术要求
- 标准规范
- 产品/设备资料
- 历史类似方案
- 企业模板

Agent 输出：

- 方案正文
- 技术路线
- 施工/实施步骤
- 材料与设备要求
- 质量控制点
- 安全环保要求
- 风险提示
- 引用依据
- 可编辑 Word/PDF/PPT

案例：

- 涂料企业输入“沿海钢结构厂房，C5-M 腐蚀环境，设计寿命 15 年”，Agent 自动推荐涂层体系，生成解决方案、施工指导书和客户推广 PPT。
- 装备制造企业输入“矿山破碎站除尘系统改造需求”，Agent 生成设备选型说明、技术方案和安装调试说明。

- 基建
- 电力
- 化工
- 矿山
- 水利

- 涂料
- 装备制造

- 作业类型
- 施工工艺
- 材料/设备
- 安全要求
- 质量验收标准
- 企业模板

Agent 输出：

- 作业条件
- 人员机具准备
- 工艺流程
- 操作步骤
- 质量控制点
- 检查记录表
- 安全环保措施

### 3.3 技术要求抽取与符合性审查 Agent

适用行业：

- 化工
- 电力
- 轨道交通
- 能源
- 装备制造
- 建筑机电
- 涂料

用户输入：

- 技术规范书
- 标准规范
- 设计说明
- 供应商资料
- 产品资料
- 检测报告

Agent 输出：

- 关键技术要求清单
- 强制性条款
- 可检查项
- 符合/不符合/需人工确认
- 风险说明
- 引用页码和原文位置
- 审查报告

案例：

- 轨交项目上传“通信系统技术规格书”和供应商提交资料，Agent 自动提取接口、性能、认证、测试要求，并生成符合性矩阵。
- 涂料企业上传客户技术要求和自家产品 TDS，Agent 判断推荐体系是否满足耐候、耐腐蚀、VOC、膜厚等要求。

- 基建
- 电力
- 能源
- 轨道交通
- 化工
- 水利
- 矿山
- 装备制造

- 验收标准

### 3.6 变更影响分析 Agent

适用行业：

- 建筑
- 基建
- 电力
- 轨道交通
- 化工
- 装备制造
- 水利

用户输入：

- 新旧版本图纸/技术文件
- 设计变更单
- 设备清单
- 施工方案
- 验收资料
- 历史问题记录

Agent 输出：

- 变更摘要
- 影响专业

- 需补充验收资料

案例：

- 轨交供电系统设计变更后，Agent 提示需要同步更新调试方案、接口文件和验收记录。
