# 工程行业文档 Agent 流程图与信息架构图

本文档基于 `engineering-document-agent-product-plan.md` 梳理，包含产品总流程、核心 Agent 工作流、信息架构、行业场景包架构和知识流。

## 1. 产品总流程图

```mermaid
flowchart TD
    A["用户发起工程文档任务"] --> B{"选择任务类型"}

    B --> B1["生成类任务"]
    B --> B2["审查类任务"]
    B --> B3["整理类任务"]
    B --> B4["分析类任务"]

    B1 --> C1["方案生成 / 作业指导书 / 推广材料"]
    B2 --> C2["技术符合性审查 / 资料缺口检查"]
    B3 --> C3["设备资料建档 / 交付包整理"]
    B4 --> C4["变更影响分析 / 风险识别"]

    C1 --> D["Agent 识别行业场景包"]
    C2 --> D
    C3 --> D
    C4 --> D

    D --> E["解析输入资料"]
    E --> E1["Word / Excel / PDF / PPT"]
    E --> E2["扫描件 OCR / 图片"]
    E --> E3["CAD / P&ID 初步索引"]
    E --> E4["历史项目资料 / 标准规范 / 产品资料"]

    E1 --> F["工程对象化理解"]
    E2 --> F
    E3 --> F
    E4 --> F

    F --> G["调用工程知识底座"]
    G --> H["执行 Agent 工作流"]

    H --> I{"是否存在缺失信息或高风险内容"}
    I -->|"是"| J["追问用户 / 标记人工确认项"]
    J --> H
    I -->|"否"| K["生成可追溯输出"]

    K --> L["Word / PPT / PDF / Excel / 审查报告 / 交付包目录"]
    L --> M["人工审阅与修订"]
    M --> N["最终交付 / 归档 / 复用沉淀"]
```
